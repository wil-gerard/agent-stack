# Planning Checklist

Use this checklist before implementation.

## Product
- [ ] Primary user is identified
- [ ] Core job-to-be-done is clear
- [ ] First complete user flow is named
- [ ] Non-goals are listed
- [ ] Prototype/MVP/production bar is clear

## Data
- [ ] Core entities are defined conceptually
- [ ] Ownership is defined for private/user data
- [ ] Relationships are clear
- [ ] Deferred entities are explicitly deferred
- [ ] No duplicate concepts exist under different names

## Auth and access
- [ ] Public/protected/admin boundaries are defined
- [ ] Ownership checks are defined
- [ ] Cross-user data access risks are called out
- [ ] Auth is not assumed to be bolted on later

## App structure
- [ ] Major routes/screens are mapped
- [ ] Styling system is chosen
- [ ] Validation pattern is chosen
- [ ] Client/server communication pattern is chosen
- [ ] Folder rules are clear

## Agent readiness
- [ ] `CLAUDE.md` or `AGENTS.md` rules can be written
- [ ] First implementation phase is small
- [ ] Things not to build yet are explicit
